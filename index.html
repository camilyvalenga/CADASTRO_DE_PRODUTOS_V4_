O Conceito do Bootstrap na V5

O Bootstrap é um framework front-end amplamente utilizado para acelerar e padronizar o desenvolvimento de interfaces web responsivas.

Nesta Versão 5 (V5), utilizamos o sistema de modais e classes utilitárias do Bootstrap para criar uma experiência de usuário (UX) moderna e fluida, eliminando os diálogos bloqueantes e arcaicos do navegador como alert() e confirm().
